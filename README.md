# domhey.github.io

Link-Seite für Duelle aus dem Spiel ROLLARIS. Ein Duell-Link
`https://domhey.github.io/rollaris/?l=…&n=…&t=…#RLX1-…` öffnet das Spiel direkt (Android-App-Link,
freigegeben durch `.well-known/assetlinks.json`). Ist das Spiel nicht installiert oder der Link nicht
verifiziert, zeigt `rollaris/index.html` das Duell an und bietet „In ROLLARIS öffnen“.

Statische Seite ohne Server, Cookies oder Tracking. Der Duell-Code steht hinter `#` und wird nie an den
Server übertragen. Quelle: Ordner `web/` im Spiel-Repository.

Schriften: Lilita One und Nunito (SIL Open Font License, siehe `rollaris/fonts/`).
